## Reflection
วันนี้ฉันเรียนรู้อะไรจากการใช้ GitHub: ได้เรียนรู้วิธีการ Fork โครงการเพื่อนำมาแก้ไขงานของตัวเอง, วิธีการแก้ไขและเขียนตารางบน Markdown รวมถึงการ Commit งานอย่างมีความหมายและการรวบรวมลิงก์ส่งงานอย่างเป็นระบบ
ฉันติดปัญหาอะไร: ในตอนแรกบัญชีไม่มีสิทธิ์เขียนงาน (Write access) บน Repository หลักโดยตรง จึงไม่สามารถกดแก้ไขไฟล์ได้
ฉันแก้ปัญหาอย่างไร: สอบถามอาจารย์และได้รับคำแนะนำให้เปลี่ยนมาใช้วิธีการ Fork โปรเจกต์มาทำในบัญชีของตนเองแทน
